# 測量小工具

TLA2（Android App）的網頁版。iPhone、Android、電腦都能用，打開過一次之後沒網路也能算。

**網址：** https://elecjpma-create.github.io/survey-tools/

## 加到手機主畫面

- **iPhone**：用 Safari 開網址 → 下方「分享」按鈕 →「加入主畫面」。
- **Android**：用 Chrome 開網址 → 右上「⋮」→「加到主畫面」或「安裝應用程式」。

## 分頁

| 分頁 | 原 TLA2 | 算什麼 |
|---|---|---|
| 經緯度→坐標 | WU60 | 經緯度（度.分秒，例 121.5959687）→ TWD97 二度分帶 |
| 坐標→經緯度 | UtoW | TWD97 二度分帶 → 經緯度（度分秒＋十進位） |
| 方位距離 | P3 | 測站、目標兩點坐標 → 方位角（度分秒）、平距 |
| 坐標推算 | P4 | 測站 N、E、Z、儀器高、覘標高，加上方位角、平距、高差 → 目標 N、E、Z（Z = 測站Z + 儀器高 − 覘標高 + 高差） |
| 角度偏移 | Angle | 偏移角 δ = atan(偏移量 ÷ 距離)；勾「往左」為夾角 − δ，不勾為夾角 + δ。夾角用「度.分秒」輸入，例 359.5959 |

坐標換算用 GRS80 橢球（a = 6378137、1/f = 298.257222101）、尺度比 0.9999、橫坐標加 250000，中央經線可選 121° 或 119°（澎湖）。

## 跟 TLA2 的差別

- 秒數四捨五入會正確進位，不會出現 60"。
- 角度偏移的結果會換算回 0–360°。
- Z、高差旁有「±」按鈕（iPhone 數字鍵盤沒有負號）。
- 中央經線可選 121° / 119°（TLA2 固定 121°）。
- 會記住上次輸入的值。
